# uni-app开发仓库管理小程序

源码地址：ym7k.com/17777/

基于 uni-app 开发的仓库管理小程序，是一套轻量化移动端仓储管理方案，依托 uni-app 跨端特性，一套工程可适配微信小程序、APP、H5 等多个终端，专注解决中小仓库、门店库房、商贸公司日常库存管理难题，摆脱传统纸质台账、电脑端系统操作不便的痛点，仓管人员手持手机就能完成大部分库房作业，实现入库、出库、盘点、库存查询、单据管理一体化。

商品档案管理是整个系统的基础功能。管理员可在后台录入商品基础信息，支持设置商品分类、规格型号、单位、成本价、预警库存、存放库区库位等信息，支持上传商品图片，方便识别。商品档案支持批量导入，不用逐条手动新增，提升建档效率。系统支持多仓库、多库位划分，适合存在分仓、分区存放货品的场景，货品可以归属到不同仓库，互不干扰，满足多地点仓储管理需求。

出入库流程是核心业务模块。入库时，仓管员可以直接在小程序上选择货品、填写数量、供应商信息，生成入库单；出库支持销售出库、领料出库、调拨出库等多种单据类型，填写出库数量、领用人员、关联订单。单据提交后库存数量自动增减，实时更新，无需事后手工汇总。单据自带编号，每一笔出入库记录永久留存，支持填写备注，方便追溯业务原因。同时支持扫码操作，通过扫描商品条码快速带出货品信息，减少手动输入出错的概率，大幅提升出入库登记速度。

库存查询与库存预警功能，帮助管理者实时掌握库存状态。操作人员可以通过小程序搜索商品名称、条码，快速查看当前库存、所在库位、最近出入库记录。系统内置库存预警机制，当货品数量低于预设下限，会自动标记提醒，管理人员打开小程序就能看到缺货清单，及时安排采购补货；也可以设置库存上限，防止货品积压过量。

库存盘点模块适配定期盘点工作。管理人员可以新建盘点任务，选定仓库或者商品分类，仓管人员现场对照实物录入实际数量，系统自动对比账面库存，生成盘盈、盘亏明细。盘点记录单独保存，差异数据清晰展示，确认后可一键调整账面库存，替代传统纸质盘点表，盘点过程更高效，盘点结果便于留存核查。

单据和数据统计模块满足对账管理需求。所有入库单、出库单、调拨单、盘点单集中归档，支持按时间、单据类型、商品筛选查询，单据详情随时查看。数据看板会汇总入库总量、出库总量、库存总值、盘盈盘亏数据，以直观方式展示仓库流转情况。数据支持导出，方便对接财务进行核算。系统支持账号权限划分，可以设置管理员、仓管员、查看员等角色，不同账号开放不同操作权限，避免越权修改库存数据。

依托 uni-app 跨端优势，这套仓库小程序开发完成后，既能在微信小程序快速使用，也可以打包成独立 APP，不用为不同平台单独开发。整体功能围绕中小仓库真实作业流程设计，轻量化、上手门槛低，兼顾日常仓储流转、库存管控和数据追溯，非常适合个体户、小型加工厂、门店库房用来数字化管货。
